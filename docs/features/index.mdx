# 核心功能概览

## P0（Demo 必做）

| 功能 | 说明 |
| :--- | :--- |
| 问题拆解 | 将用户问题自动拆为 3-5 个子搜索词 |
| 多轮联网搜索 | 并行搜索，覆盖 500-1000 网页 / 次 |
| 交叉验证 | 同一观点至少 2 个独立信源，冲突则并列 |
| 引用标注 | 每个数据点标注来源 + 链接 + 时间，末尾附参考清单 |
| 报告生成 | 结构化输出（摘要 → 分点详述 → 风险提示 → 参考资料） |
| 私有数据上传 | 支持上传 PDF / Word，优先检索内部知识库 |

## 功能详述

### 问题拆解

用户输入自然语言研究问题，由 LLM 自动拆解为 3-5 个可搜索的子关键词。
拆解结果对用户可见，便于校验和手动调整。

### 多轮联网搜索

基于拆解出的子关键词，并行执行多轮搜索：
- 每个子词返回 3-5 条结果
- 单次任务覆盖 500-1000 个网页
- 使用 Tavily / Bing 搜索 API，不使用任何金融数据 API

### 交叉验证

对同一观点强制交叉验证：
- 至少 2 个独立信源相互印证
- 信源冲突时并列展示，不擅自裁决
- 低权威信源标注 **"非机构观点"**

### 引用标注

报告中所有数据点必须标注：
- 来源（机构 / 媒体 / 社区）
- 原文链接
- 发布时间
- 末尾附完整参考资料清单，无遗漏

### 报告生成

输出结构化报告，固定包含以下部分：

1. **摘要** — 核心结论的一段式概述
2. **分点详述** — 按主题分点展开，每点带引用
3. **风险提示** — 数据局限性、信源冲突点
4. **参考资料** — 全部引用的来源清单

### 私有数据上传

支持用户上传 PDF / Word 格式的内部资料：
- 上传后进入本地 RAG 向量检索
- 提问时优先检索内部资料
- 再补充公开信息作为佐证
