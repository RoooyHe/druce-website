# 产品需求文档（精简版）
## AI投研助手 - 初步报告模块

**版本**：V1.0 | **日期**：2026.07.31 | **状态**：Demo阶段


## 一、产品定位

面向投研人员的**AI信息聚合工具**，输入一个研究问题，自动执行多轮搜索、交叉验证，生成带引用链接的结构化报告。**核心差异**：支持批量接入私有数据（内部研报/纪要），而非仅依赖公开信息。

**一句话卖点**：花5分钟得到别人花5小时手动搜索才能凑齐的行业情报。


## 二、目标用户与场景

| 用户 | 场景 | 核心诉求 |
| :--- | :--- | :--- |
| 买方研究员 | 周报/晨会素材搜集 | 快、广、可信 |
| 投资经理 | 验证个人判断框架 | 私有数据融合、定制化分析 |
| 个人投资者 | 自选股盯盘与异动归因 | 实时提醒、社区情绪监控 |


## 三、核心功能

### P0（Demo必做）

| 功能 | 说明 |
| :--- | :--- |
| 问题拆解 | 将用户问题自动拆为3-5个子搜索词 |
| 多轮联网搜索 | 并行搜索，覆盖500-1000网页/次 |
| 交叉验证 | 同一观点至少2个独立信源，冲突则并列 |
| 引用标注 | 每个数据点标注来源+链接+时间，末尾附参考清单 |
| 报告生成 | 结构化输出（摘要→分点详述→风险提示→参考资料） |
| 私有数据上传 | 支持上传PDF/Word，优先检索内部知识库 |



## 四、数据来源策略（无金融API方案）

| 类型 | 来源 | 获取方式 |
| :--- | :--- | :--- |
| 公开研报 | 东方财富研报中心、雪球、格隆汇 | 搜索引擎爬取 |
| 公告/财报 | 巨潮资讯网 | 搜索引擎+PDF解析 |
| 新闻资讯 | 新浪财经、华尔街见闻 | 搜索引擎 |
| 私有数据 | 用户上传PDF/Word | 本地RAG向量检索 |
| 社区情绪 | 雪球、东财股吧 | 搜索引擎限定站点 |


## 五、技术栈

| 层 | 选型 | 说明 |
| :--- | :--- | :--- |
| 前端 | Streamlit | 快速Demo，无需前端开发 |
| Agent编排 | LangChain / MCP | 任务拆解、工具调度 |
| 搜索 | Tavily API / Bing API | **不使用任何金融数据API** |
| 私有知识库 | Chroma + PyPDF | 向量检索+PDF解析 |
| LLM | GPT-3.5-turbo / DeepSeek | 低成本，DeepSeek为OpenAI 1/10 |
| 异步任务 | Celery + Redis（可选） | 长任务不阻塞界面 |


## 六、数据流（核心流程）

用户输入问题
    ↓
LLM拆解为3-5个子搜索词
    ↓
并行执行搜索（每词3-5条结果）
    ↓
合并搜索结果 + 用户私有数据（如有）
    ↓
LLM生成带引用的结构化报告
    ↓
前端展示 + 来源追溯


## 七、验收标准

| 编号 | 验收项 | 标准 |
| :--- | :--- | :--- |
| AC-01 | 问题拆解 | 自动生成≥3个子搜索词，用户可见 |
| AC-02 | 信源数量 | 每个观点至少2个独立来源 |
| AC-03 | 引用规范 | 所有引用含来源+链接+时间，无遗漏 |
| AC-04 | 私有数据 | 上传后优先引用内部资料，再补充公开信息 |
| AC-05 | 响应时间 | 单次报告≤15分钟 |


## 八、Demo展示场景（3个）

1. **多源聚合**：输入"本周电子行业观点"→ 展示搜索→交叉验证→带引用报告

2. **私有数据优势**：上传内部纪要 → 提问"这家公司近期有无公开更新？"→ 展示私有+公开融合回答

3. **框架对齐**：输入"按巴菲特护城河框架，分析我自选股"→ 展示按指定逻辑筛选点评


## 九、风险与应对

| 风险 | 应对 |
| :--- | :--- |
| 搜索内容质量参差 | 强制交叉验证，低权威信源标注"非机构观点" |
| 爬虫被封 | 优先用搜索API，不硬爬特定站 |
| LLM幻觉/伪造来源 | Prompt强制"无结果如实告知"，后处理校验链接 |
