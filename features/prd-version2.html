    #AlphaAgent — 多视角 AI 金融投研助手

    产品需求文档 v2。本文沉淀自 druce-website/docs/prd-version2.md,作为面向读者的产品文档入口。

    #1. 文档信息与项目背景

    #1.1 核心定位

    基于开源数据源与 Agent 协同架构,融合确定性代码计算与多投资哲学(价值/成长/风控)碰撞,提供零幻觉、可追溯的公司深度投研报告。

    #1.2 解决痛点

    • 传统大模型做金融分析易产生数字幻觉、计算不精准。
    • 单一 LLM 生成的研报观点平庸、同质化,缺乏多维度博弈视角。
    • 商业金融数据库成本昂贵,缺少面向开发者和中小投资者的零成本自动化投研工具。

    #2. 产品总体架构设计

    系统采用 "确定性计算 + 多 Agent 协同推演 + 反思审核" 的三层架构:

    1. 层 1:数据采集与确定性计算引擎 (Data Engine) — 调用 AKShare / 巨潮资讯,解析 PDF 财报与基础行情,计算财务比率。
    2. 层 2:多视角投资框架 Agent — 价值派 / 成长派 / 风控派三 Agent 并行归因推演。
    3. 层 3:分歧辩论与综合研判 + 反思核查 Agent — 汇总共识与分歧,逐句核查数据来源,剔除数字幻觉。

    #3. 核心功能模块与需求明细

    #3.1 模块一:数据采集与确定性计算引擎 (Data Engine)

    需求目标:获取基础数据并完成所有数值计算,保证大模型不参与基础算术。

    数据源规划:

    数据类型数据源
    行情/财务报表AKShare (Python 开源接口)
    官方公告/财报文本巨潮资讯网 (cninfo) 抓取 PDF/文本
    新闻/舆情Tavily / Serper API 或 AKShare 个股新闻接口

    功能需求:

    1. 自动提取近 3~5 年三大财务报表(资产负债表、利润表、现金流量表)。
    2. 确定性计算:在 Python 侧直接计算出 ROE、毛利率、净利率、资产负债率、应收账款周转天数、PEG、经营性现金流/净利润比值等指标。
    3. 规则预警打标:若触发特定异常规则(如:应收账款增速 > 营收增速 + 15%),自动打上警告标签 [Anomaly_Tag] 传给后续 Agent。

    #3.2 模块二:多视角投资框架 Agent (Multi-Perspective Agents)

    需求目标:对同一组确定性数据,从不同投资哲学维度进行并行归因推演。

    #1) 巴菲特式价值派 Agent (Value Agent)

    项目说明
    分析维度护城河(品牌/转换成本)、ROE 稳定性、自由现金流、债务风险
    硬性规则若连续 3 年 ROE < 12% 或资产负债率 > 60%,扣除护城河得分
    输出格式【看多/观望/看空】+ 护城河逻辑 + 最关心风险

    #2) 彼得·林奇成长派 Agent (GARP Agent)

    项目说明
    分析维度营收与净利增速、PEG 指标、存货与营收匹配度
    硬性规则评估 PEG 是否在 0.5~1.2 的合理成长区间,检查存货是否异常堆积
    输出格式【看多/观望/看空】+ 成长匹配度逻辑 + 拓展潜力

    #3) 风控与做空视角 Agent (Risk Agent)

    项目说明
    分析维度寻找财报隐患、非经常性损益占比、现金流断裂隐患
    硬性规则重点扫描 [Anomaly_Tag],审查商誉占比与应收账款坏账风险
    输出格式【低/中/高风险】+ 核心财务隐患清单

    #3.3 模块三:分歧辩论与综合研判 Agent (Debate & Consensus Agent)

    需求目标:汇总各 Agent 评估结果,寻找"共识"与"分歧",输出综合投资建议。

    功能需求:

    • 生成多视角对比矩阵(Dashboard 表格)。
    • 提取共识点(如:产品市场需求持续增长)。
    • 梳理核心争议点。
    • 给出分人群操作建议(如:适合成长型资金,保守价值资金建议观望)。

    #3.4 模块四:反思核查与数据可追溯模块 (Auditor Agent)

    需求目标:解决幻觉,确保生成报告的可信度。

    功能需求:

    • 溯源标注:对报告中涉及的每一个具体财务数据,自动附带出处索引,对生成的文本与 Data Engine 提供的数据进行二次比对。若发现数字不符或无中生有,打回重写。

    #4. 输出成果规范 (Deliverable Format)

    Agent 最终输出的报告严格遵循以下五章结构(Markdown 格式):

    #第一章:摘要与多视角判定矩阵

    定位:给决策者看的"结论先行"仪表盘。无需阅读全篇,1 分钟内掌握核心分歧与结论。

    #1.1 公司摘要及核心结论

    基于多 Agent 综合研判,给出公司摘要和投资建议。

    #1.2 投资视角碰撞矩阵

    用标准 Markdown 表格展现各角色的分歧。

    投资视角投资判定核心逻辑摘要匹配度/风险得分
    价值派看多/观望/看空xxxxx/100
    成长派看多/观望/看空xxxxx/100
    风控派低/中/高风险xxxxx/100

    #1.3 核心分歧点与共识总结

    共识:所有 Agent 达成一致的事实

    • 例如:"公司产品在海外市场增速确实达到 45%"

    分歧:不同视角争论的焦点

    • 例如:"价值派认为高研发削弱了当期利润,创新派认为这是构筑技术壁垒的必要投入"

    #第二章:基础数据与确定性指标分析

    定位:展现系统的零幻觉底座。所有数据由 Python/AKShare 确定性计算,不依赖大模型猜测。

    #2.1 财务健康度硬指标

    维度指标数值评价
    盈利能力ROExx%优秀/一般/较差
    盈利能力毛利率趋势xx%稳定/下滑/提升
    盈利能力净利润率xx%优秀/一般/较差
    成长性营收增速xx%高速/中速/低速
    成长性净利润增速xx%高速/中速/低速
    偿债与现金流资产负债率xx%健康/偏高/危险
    偿债与现金流经营性现金流/净利润x.x健康/警惕

    #2.2 估值与市场表现

    指标当前值历史分位数行业平均
    PExxxx%xx
    PBxxxx%xx
    PSxxxx%xx
    PEGx.x——

    #2.3 异常指标自动预警

    记录系统通过规则计算触发的异动标记:

    • [预警] 应收账款增速 (42%) > 营业收入增速 (15%)
    • [预警] 存货同比增速 (25%) > 营收同比增速 (8%)

    #第三章:经典投资框架深度推演

    定位:展示 3 个独立 Agent 站在不同投资哲学下的深度推演。

    #一、价值派 (巴菲特/芒格 视角)

    核心逻辑:追求自带高护城河、现金流极其充沛、资产负债表干净的好公司。

    #1. 核心指标与定量阈值表
    指标名称计算公式优选数值/门槛 (看多)警告/剔除数值 (看空)数据来源/字段
    净资产收益率 (ROE)归母净利润 / 平均归母净资产近 5 年平均值 > 15%,且单年最低不低于 12%近 3 年平均值 < 10%,或波动标准差 > 8%利润表 / 资产负债表
    自由现金流 (FCF)经营活动现金流量净额 - 资本开支连续 3 年为正,且 FCF/归母净利润 ≥ 0.8近 3 年有 2 年为负,或比值 < 0.3现金流量表
    毛利率及其稳定性(营业收入 - 营业成本) / 营业收入毛利率 > 30%,且近 5 年极差 < 5%毛利率 < 15%,或近 3 年连续下滑利润表
    资产负债率总负债 / 总资产< 40%(金融/建筑行业除外)> 60%资产负债表
    现金保障度(货币资金 + 交易性金融资产) / 总资产> 15%< 5%资产负债表
    #2. 代码/Prompt 硬性判定规则
    • 看多(Pass):ROE > 15% AND FCF 为正 AND 资产负债率 < 40%
    • 一票否决(Reject):若连续 2 年 FCF 为负,无论利润多高,判定为【非价值标的】

    #二、成长派 (彼得·林奇 GARP 视角)

    核心逻辑:寻找"合理价格下的高成长",将业绩扩张速度与估值进行匹配。

    #1. 核心指标与定量阈值表
    指标名称计算公式优选数值/门槛 (看多)警告/剔除数值 (看空)数据来源/字段
    PEG 指标动态 PE / 未来 3 年预计净利润复合增速0.5 ≤ PEG ≤ 1.0PEG > 1.5 或 PEG < 0.3行情 / 利润表 / 券商一致预期
    营业收入复合增速本期营收与 3 年前同期营收的年化增速> 20%< 8%(增长停滞)利润表
    利润/营收增速差净利润同比增速 - 营收同比增速> 0%< -10%(增收不增利)利润表
    存货与营收增速差存货同比增速 - 营收同比增速≤ 0%> 15%(存货堆积)资产负债表 / 利润表
    研发投入占比研发费用 / 营业收入> 8%(科技/医药类)< 2%(缺乏技术护城河)利润表附注
    #2. 代码/Prompt 硬性判定规则
    • 看多(Pass):营收增速 > 20% AND 0.5 ≤ PEG ≤ 1.0 AND 存货增速低于营收增速
    • 一票否决(Reject):若营收增速连续 2 个季度同比 < 5%,判定为【成长逻辑破灭】

    #三、风控与做空视角

    核心逻辑:基于"怀疑论",验证利润的含金量与资产负债表的问题。

    #1. 核心指标与定量阈值表
    筛查维度核心指标与计算公式正常/安全区间预警数值检查目的
    真金白银验伪收现比 = 销售商品收到的现金 / 营业收入≥ 0.9< 0.7警惕虚构营收
    主业造血能力扣非利润占比 = 扣非净利润 / 归母净利润> 85%< 60%警惕靠政府补贴、卖房凑利润
    商誉减值商誉占比 = 商誉 / 归母净资产< 10%> 20%高溢价并购留下的巨大隐患
    应收账款异动应收增速差 = 应收账款增速 - 营收增速≤ 5%> 15%警惕提前确认收入、放宽信用
    存贷双高异动高货币资金 + 高有息负债利息收益与利息支出匹配账面现金 > 30% 却大量举债警惕大股东占用资金
    #2. 代码/Prompt 硬性判定规则
    • 低风险(Low Risk):收现比 > 0.9 AND 商誉占比 < 10% AND 应收增速差 < 5%
    • 高风险触发(Red Flag):若触发"收现比 < 0.7" 或 "商誉/净资产 > 20%",标记为【高风险/财务粉饰嫌疑标的】

    #第四章:数据可追溯性与事实核查

    定位:展现 AI 设计的严谨性,解决大模型幻觉问题。

    #4.1 关键事实溯源表

    数据/观点数值原始出处

    应收账款增速42%巨潮资讯 - 2024 年报 P.45
    商誉/净资产22.3%巨潮资讯 - 2024 年报 P.56
    .........

    #4.2 审查 Agent 修正记录

    展示系统自我修正的过程:

    版本问题描述修正动作
    初稿误将拟投资金额认作已支出金额审查 Agent 校验后打回修正
    初稿引用 PE 分位数数据错误与 Data Engine 二次比对后更正

    #第五章:情景推演与投资策略建议

    定位:从分析走向落地决策。针对不同类型投资者的操作建议:

    投资者类型建议关键关注指标
    保守型/价值资金建议观望,等待特定风险指标改善后再入场应收账款增速、商誉占比
    稳健型资金可小仓位参与,关注 PE 分位数ROE 趋势、股息率
    激进型/成长资金可逢低建仓,必须设定严格止损位(如破位 10% 止损)营收增速、PEG 区间
