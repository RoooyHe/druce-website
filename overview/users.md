# 目标用户与场景

| 用户    | 场景          | 核心诉求         |
| :---- | :---------- | :----------- |
| 买方研究员 | 周报 / 晨会素材搜集 | 快、广、可信       |
| 投资经理  | 验证个人判断框架    | 私有数据融合、定制化分析 |
| 个人投资者 | 自选股盯盘与异动归因  | 实时提醒、社区情绪监控  |

## 买方研究员

需要快速汇集行业观点、公司动态、研报数据，用于周报、晨会素材准备。核心诉求是 **快、广、可信**：
通过多轮联网搜索与交叉验证，覆盖 500-1000 个网页，确保信息来源可靠。

## 投资经理

希望验证自己的投资判断框架。核心诉求是 **私有数据融合、定制化分析**：
将内部纪要、个人研报上传至知识库，提问时优先检索内部资料，再补充公开信息作为佐证。

## 个人投资者

关注自选股的实时动态与异动归因。核心诉求是 **实时提醒、社区情绪监控**：
通过限定站点搜索聚合雪球、东财股吧等社区情绪，辅助决策。
